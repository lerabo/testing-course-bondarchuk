# Наскрізний проєкт курсу тестування ПЗ

**Студентка:** Бондарчук Валерія, група КНІТ-63М.

## Застосунок

Навчальний вебзастосунок «Система управління студентами» — облік студентів і їхніх оцінок на факультеті, REST API та вебінтерфейс. Ролі: адміністратор (деканат), викладач, студент.

## Мова і фреймворки (попередній вибір)

Python 3 і pytest для модульних та інтеграційних тестів, pytest-bdd для сценаріїв Gherkin, httpx для тестування REST API, Playwright для E2E-тестів інтерфейсу, Locust для навантажувального тестування, mutmut для мутаційного тестування.

## Використання ШІ

Claude (Anthropic) використано як допоміжний інструмент.

- ЛР 1: перевірка формулювань вимог, оформлення Markdown і сценаріїв Gherkin. Дефекти, оцінки ризиків і вибір характеристик якості перевірено й погоджено авторкою.
- ЛР 2: допомога з поясненням правил Ruff і Semgrep, формулюванням коментарів рецензії та налаштуванням CI. Кожен коментар рецензії перевірено запуском коду (наприклад, `ects_grade(90)` повертає `B`). ШІ, як і лінтер, спершу пропустив невикористаний `import os`.
- ЛР 3: допомога з оформленням таблиць і скрипта, який виконує тести в консолі Python та записує фактичні результати. Класи, таблицю рішень і діаграму станів спроєктовано за специфікацією без перегляду коду; ШІ спершу не врахував, що поєднання «є Fx» і «середній ≥ 90» можливе за великої кількості оцінок.
