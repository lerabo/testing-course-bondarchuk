## Висновок для замовника

Версію 0.10.0 випускати не можна. Три нефункціональні вимоги не виконано, і причина кожної - конкретний дефект із вимірами. Продуктивність: на потоці з 300 студентів сервер обробляє ~9 запитів/с замість 20, а за 20 запитів/с більше половини запитів закінчуються тайм-аутом (#84). Безпека: режим налагодження ввімкнено за замовчуванням, і відповідь 500 показує код сервера (#76); залежність python-multipart має шість відомих вразливостей, частина з них - відмова в обслуговуванні без автентифікації (#85); експорт CSV не захищає від формул (#77); один некоректний рядок імпорту вимикає список для всіх (#79). Доступність: сортування недоступне з клавіатури (#81), поле імпорту без мітки (#80).

Умови випуску: виправлено #76, #77, #79, #84 і #85 (оновлення python-multipart до 0.0.31 або новішої), додано заголовки CSP і захисту від clickjacking (#86, #87), виправлено #80 і #81; відповідні тести xfail після цього стають зеленими (`strict=True` змусить зняти позначки), k6 за 20 запитів/с - код виходу 0, нічний процес `security` - зелений. #78, #82 і #83 можна випустити як відомі обмеження з виправленням у наступній версії: вони погіршують зручність, але не відкривають даних і не блокують функцій.
