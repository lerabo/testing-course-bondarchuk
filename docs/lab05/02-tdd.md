# Протокол TDD для Р-21

Функція `retake_date(exam_date, semester_end, holidays=())` у модулі `student_portal.retake`; тести — `app/tests/lab05/test_retake.py`. Робота в гілці `feature/retake-date`, злиття звичайним merge.

## Перелік тестів (записано до коду)

Від найпростішої поведінки до найскладнішої; класи й межі — як у ЛР 3.

1. Іспит у понеділок → перескладання в понеділок через тиждень (найпростіший випадок).
2. Іспит у середу → середа через тиждень (тріангуляція: друга точка для узагальнення «+7 днів»).
3. Дата через тиждень припадає на суботу → наступний понеділок.
4. Дата через тиждень припадає на неділю → наступний понеділок.
5. Дата через тиждень — свято (25.12) → найближчий робочий день, з урахуванням вихідних після свята.
6. Кілька свят поспіль → перший робочий день після них.
7. Найближча допустима дата пізніше за кінець семестру → `NoRetakeDateError` з датою кінця семестру в повідомленні.
8. Межа: найближча дата дорівнює останньому дню семестру → дозволено.
9. Вихідні переносять дату за межу семестру (кандидат у межах, але перенесена дата — ні) → `NoRetakeDateError`.
