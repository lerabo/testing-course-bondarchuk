# Таблиця рішень (Р-17)

Функція `scholarship(student)`. Передумова всіх тестів — студент зі статусом «навчається». Оцінка Fx — бали нижче 60 (у тестах 59 і менше).

**Умови:** У1 — державне замовлення (Т/Н); У2 — є оцінка Fx (Т/Н); У3 — середній бал з розширеними входами: «немає оцінок», «< 75», «75–90» (від 75 до 90 не включно), «≥ 90». Випадок «немає жодної оцінки» віднесено до У3, бо без оцінок середнього бала не існує. **Дії:** Д1 — не призначено, Д2 — звичайна, Д3 — підвищена.
