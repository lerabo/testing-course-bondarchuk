# Реєстр ризиків

**Ймовірність:** 1 — малоймовірно, 2 — можливо, 3 — дуже ймовірно. **Вплив:** 1 — незручність без втрати даних, 2 — порушення функції з обхідним шляхом, 3 — неправильні оцінки, втрата або витік даних. **Рівень** = ймовірність × вплив: 1–2 низький, 3–4 середній, 6–9 високий.
